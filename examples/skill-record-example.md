# 证据强度判断

> **这是示例**：来自真实训练的一份技能记录，个人信息已去除。它展示了严格记录的样子：没有提示时答不出就写答不出，提示后部分答对就写部分答对，讲解后的即时复述不作为升级依据。文中的 `[[双链]]` 指向原知识库里的其他笔记，在本仓库里不存在。

## 能力定义

面对一个「模型内部有某个表示，并且用到了它」的主张，能判断现有证据属于哪一级（相关、探针、归因、干预、泛化），说出它能支持什么、不能支持什么，并设计一个能区分竞争性解释的对照实验。

## 最近练习

### 2026-10-18 · [[gradient-attribution]] · 为什么梯度归因高不等于因果

- 任务：不看答案，说出至少两条理由，以及用什么实验补救。
- 无提示时的表现：「不知道，看论文没看出来。」没有给出任何理由。
- 给了两个提示以后：
  - 提示一（`f(h) = min(h,1)`，h = 3）→ 答「在平的地方梯度为 0，比如 ReLU 这些不平滑的地方」。**部分正确**：找到了饱和失效，但把原因归到「不平滑」上（平滑的 sigmoid 饱和时也一样）；没有上升到「梯度是一阶、局部的」；没有提到反方向的情况（梯度大但大幅改动的效果会被抵消）；也没有直接回答题里要求的两个数值。
  - 提示二（振幅和能量的混杂）→ 答「没法确定读出来的真是能量，别的信息也可能和能量成正比」。**推理正确**（混杂变量）。但**事实前提错误**：说能量维度是「用 SAE 读出来的」，实际上是在原始残差流上用逐维皮尔逊相关挑出来的。
- 错误类型（手册 §10.3）：不理解公式中的变量（梯度的局部性）；概念混淆（SAE 与逐维相关，第二次出现，见 [[paper-reading]]）。
- 补救实验部分：给了「怎么确定开关控制着灯」的提示以后，答「不动开关看灯，以及动开关看灯，也就是控制其他的输入」。**概念正确**：说出了干预加控制变量。但不会落实到模型上（原话：「不知道怎么对那个能量维度操作」）。具体做法由 Agent 直接讲解：均值消融加随机维度对照、A/B 轨迹间的 activation patching、用回归探针方向做 steering 加随机方向对照，以及用「振幅相同、k 不同」的样本对来解开振幅和能量的混杂。
- 讲解后的即时复述：「直接去修改能量维度的值：1. 改成平均值，结果要变差；2. 改成一个特殊值，看结果；3. 逐渐变化，看是否正相关。」三种操作基本说对。不足之处：
  - 把「变差」说成必然结果，实际上它是要检验的假设（不变就说明表示是惰性的）。
  - 「特殊值」没说清要取自另一条真实轨迹（保持在分布内，而且目标已知）。
  - **三种操作都没提对照组**（随机维度、随机方向、振幅相同 k 不同的样本对）。
  - 这次复述紧跟在讲解之后，不能作为升级依据。
- 状态依据：`needs-hints`。依据本次练习，两条理由和补救思路都是在提示下才得出的，其中一条带有事实错误；具体的干预操作完全靠讲解。
