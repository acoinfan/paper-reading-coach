# 读图方法

## 两条总原则

1. **先把图里所有的变量看懂，再看数据。** 轴、图例、颜色条的范围，以及图注里写的模型、层、样本数。开口之前先把轴和图例的标签**原样念一遍**。最常见的错误是把上一张图的读法直接搬到这一张，或者猜错颜色代表什么。
2. **每个数字都问「和什么比」。** 除了和图里的其他条件比，还要和基线比：
   - 论文画了随机线，就用它（例如随机猜测的准确率、AUROC 0.5）。
   - **论文没画，就自己估一个。** 例如：在 d 维空间里，一个随机方向和 r 维子空间的典型夹角约为 arccos(√(r/d))。d = 2560、r = 2 时约 88.4°，所以「夹角接近 90°」本身并不说明什么。
   - **捷径基线**：照抄上下文、排除法、记忆常见答案能拿多少分？
   - **噪声基线**：只换随机种子重新训练，数值会变多少？

## 读图五问

1. 这张图想回答什么问题？
2. 数据来自哪里？（模型输出，还是内部表示的分析？）
3. 轴、图例、颜色、误差条各代表什么？
4. 直接看到了什么？（只写现象）
5. 能支持什么？还不能证明什么？

第 5 问固定先问自己两件事：

- 这是「**读得出来**」的证据，还是「**被用上了**」的证据？相关、探针只能说明前者；要说明后者，需要干预（消融、patching、steering）和匹配的对照。
- 有没有可能是**捷径**造成的？（照抄、泄漏、记忆）

## 热图怎么读

以「交叉探针」热图为例：横轴是探针训练用的条件，纵轴是被读取数据的条件，格子里是读取效果。

1. **先看两条轴**：两条轴通常都是类别。一格代表什么，用一句话说出来。
2. **看颜色条的范围**：范围很窄时，颜色会放大差别。0.66 看起来很浅，但可能离随机的 0.5 还很远。
3. **先看对角线**：两条轴取同一条件时的值，常常是「上限」或「自身对照」。
4. **再看离开对角线的格子**：哪一行、哪一列特别不同？差得越远是否越浅？
5. **看紧挨对角线的一斜排**：相邻条件之间的变化，常常对应「收敛」或「渐变」。
6. **三角形热图**：只画一半通常是因为指标对称，对角线为 1 通常是因为和自己比。

## PCA 图怎么读

- PCA 找出「所有点散得最开」的几个方向，把高维数据投影上去画。坐标轴上的百分比是这个方向解释的总差异比例。
- 先确认：**每个点代表什么**（一个 token？一个样本的平均？），**颜色代表什么**，**连线连的是什么**，PCA 是否对所有点**联合拟合**（联合拟合时不同颜色的位置才能直接比较）。
- 看：各组是否分开、沿哪个主成分排列、组间间距怎么变化。
- 注意：
  - 主成分的百分比很小时，图上的分离只占总差异的一小部分。
  - PCA 是投影，距离和角度都会失真；「垂直」「平行」这类结论要看论文给的数值，不能从 PCA 图上直接读。
  - 往往只画了一个样本、一层、一个模型。

## 正文措辞和数据不一致时

正文常用比数据更强的词（如「fail」「completely」）。读图时把正文的说法和格子里的数字对一下，并记在卡片的「文档内的不一致」或「局限」里。
